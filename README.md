# safe-space-app
Safe Space is an iOS application developed using Swift to raise awareness about domestic violence.
The application focuses on providing a simple, fast, and user-centered interface inspired by awareness systems such as KADES.

This project was developed as a university social responsibility and awareness study and is intended for educational and conceptual purposes only.

Features

Simple and accessible user interface

Awareness-focused design for critical situations

Quick navigation with minimal user interaction

Technologies

Swift

UIKit / SwiftUI

Xcode
